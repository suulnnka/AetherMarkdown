# 编辑交互行为规范

定义编辑面的一切交互行为，与 `src/edit/keyboard.js` / `surface.js` 的实现一一对应。

## 1. 总则

- **统一起始显示位置**：所有行块（标记 + 正文）一律从编辑面内容左缘向右排列——渲染态的项目符号/编号/复选框与编辑态的 `## ` / `- ` / `1. ` 等前缀都行内排在行首，正文跟随其后；没有任何元素悬挂到起始位置左侧。嵌套缩进统一由左边距表达（列表每 2 个前导空格一级），编辑态的前导空格零宽收纳（字节保留在 DOM 中）。
- 编辑容器整体 `contenteditable`，所有行块为其直接子元素（扁平结构）；跨块选区、光标移动沿用浏览器原生行为。
- 光标所在块 = 活动块，进入**编辑态**：保持该块的渲染排版（标题仍是标题字号、粗体仍是粗体），语法标记（`#`、`**`、`- `、`](url)`、pipe、硬换行空格等）以 `md-marker` 弱化色（`--md-marker`）内联显示，无底色。编辑态 DOM 的纯文本与该块源码逐字节一致。
- 其余块为渲染态（语法标记隐藏）。切换不改源文本、不进 undo 栈。
- 渲染态块中：链接可点击（新标签打开），图片可点击（发出 `imageClick` 事件，宿主处理），其余点击 = 将该块变为活动块并定位光标。
- **编辑器不代写语法**：没有任何"输入前缀 + 空格自动转换"输入规则，结构标记一律由用户手写。

## 2. 键盘行为表

| 键 | 行为 |
|---|---|
| `Enter` | **分行**：插入换行符，光标到新行行首（新行是真实的行块；行中回车即拆分当前行）。代码块/表格内一律插入换行（表格内 Shift+Enter 也不加硬换行空格，避免拆坏行结构；Enter 拆出的行仍是 `|` 行则仍属同一表格） |
| `Shift+Enter` | **短间距行**：插入"两空格+换行"，下一行渲染为短间距（`md-gap-short`，间距 `--md-br-hard-gap`，默认 0） |
| `Tab` | 列表行整行缩进 ±2 空格；代码块内插入两空格；其余无操作 |
| `Backspace`（行首） | 剥一层语法：标题→文字行、列表行降缩进/去标记、引用降一层、分隔符删一个标记字符（`---`→`--` 即成普通行）；已是最简则与上一行**并行合并**（直接拼接，删除行边界，并清上一行行尾硬换行空格）。紧邻上一行是分隔符时退格删其末尾一个标记字符，行不合并 |
| `Backspace`/`Delete`（其余） | 浏览器默认编辑，input 事件同步；有选区时删除选区 |
| `Delete`（行尾） | 与下一行并行合并；本行或紧邻下一行是分隔符时只删一个标记字符，行不合并 |
| `Ctrl/Cmd+Z` / `Shift+Z`（`Ctrl+Y`） | 撤销 / 重做（快照栈） |
| `Ctrl/Cmd+C/X/V` | 复制=源文本；粘贴纯文本化 |

**分隔符行（`---`，D38）**：**可编辑行**。渲染态显示为横线，上下各 1em 间距以 padding 实现——整条带域都是该行的可点击区域（点不中/误触下方行的问题）；点击带域任意位置 = 该行进入编辑态显示 `---` 源码（光标行尾），可直接增删字符——少于 3 个标记字符即自动变回普通文字行。跨界删除同样按"每次一个字符"处理：下一行行首退格删分隔符末位字符、上一行行尾 Delete 删其首位字符，行不合并。

## 3. 活动块切换细则

- 进入（点击渲染态块 / 选区移入）：块内容替换为源码形态，光标按映射恢复到对应位置。
- **边缘点击兜底**：点击行块首/尾边缘时，WebKit 常把选区落在 surface 层级（元素偏移而非文本节点）——此时折算激活首个/末个可编辑单元（行首/行尾），否则输入会插到无单元管辖的区域并被随后的重渲染清除。
- **边界吸附**：点击落在可见内容的最前/最后一个光标位时，光标对齐源码**内容起点**（前缀之后）与**源码行尾**——否则行尾隐藏的行内语法（`**`、`](url)` 等）会把光标留在源码行中部。行中间的点击仍走精确映射。
- 离开：块渲染化，渲染结果与再次进入时完全一致（源文本未变）。
- 跨块选区（非折叠）**不触发**激活：覆盖的块保持渲染态；对选区的删除/复制经"DOM 选区 → 源文本区间"翻译后直接作用于源文本。
- IME 合成期间禁止切换（合成结束才处理），见 §7。
- 失焦：活动块渲染化，触发 `blur` 事件。

## 4. 链接行为（D14）

- **点击渲染态链接：浏览器新标签打开**（`target="_blank" rel="noopener noreferrer"`），编辑态与只读态一致。点击链接**不进入编辑态**（mousedown 不落光标，行保持渲染态）——否则行被切成源码后 click 落点失效，链接打不开。
- 想编辑链接文本/URL：用方向键把光标移进该块（块变源码态后 `[text](url)` 可编辑），或点击该块中链接以外的文字。
- 链接元素不拦截方向键：键盘导航穿过链接时正常移动光标。

## 5. 图片行为（D11/D12 修订）

- 渲染：`<img>` 带 alt。显示尺寸受约束：宽度不超过内容列（`--md-content-width`），高度不超过 `--md-img-max-height`（默认 `75vh`），始终保持纵横比。
- **点击图片：库发出 `imageClick` 事件（图片 src），放大/查看由宿主自行处理**。宿主未监听 `imageClick` 时，点击回落为激活该块（图片是原子元素，浏览器点击不落文本光标，需显式激活后编辑图片语法）。
- 只提供 URL 形式的图片输入（`![alt](url)`），无上传/粘贴/拖拽通道。

## 6. 复制 / 剪切 / 粘贴

- **复制**：选区（含跨块）映射回源文本区间，以 `text/plain` 写入剪贴板 → 复制出的就是 Markdown 源码。
- **剪切**：复制 + 删除选区（一个 undo 单元）。
- **粘贴**：只取 `text/plain`，丢弃 HTML 与文件（D17）。文本按源偏移插入（换行符原样进入，重解析后自然成行），光标落在粘贴内容末尾。整个粘贴为一个 undo 单元。

## 7. IME

- 合成期间（`compositionstart`→`compositionend`）：不重渲染、不切活动块、不动 DOM 结构；光标合成行为交给浏览器。
- 合成结束：统一同步源文本、走正常数据流；一次合成为一个 undo 单元。
- 零容忍缺陷：丢字、断字、候选窗错位、合成中被重渲染。

## 8. 撤销 / 重做（D15）

- 单元划分：同块 500ms 连续输入合并（光标移动/换块切分）；结构操作（回车、合并、剥层、缩进、粘贴、选区删除）各自独立。
- undo/redo 后光标回到快照记录的源偏移，并保证所在块为活动块。
- undo 栈在 `setValue(value, { resetHistory: true })` 时清空（默认 true）。

## 9. 只读模式（D19）

- 容器 `contenteditable=false`，无光标、无键盘行为、无 undo。
- 链接仍可点击打开，图片点击仍发出 `imageClick` 事件。
- `setReadonly(v)` 运行时切换；切换不清空文档与 undo 栈。

## 10. 其他边界

- **空文档**：显示一个空的可编辑块（一个空行块），无占位文案。
- **文档首尾**：始终可移动到首/尾；末块之后回车即新增行块。
- **选区全选（Ctrl/Cmd+A）**：选中容器内全部（浏览器原生），删除 = 清空为一个空块。
- **拖放**：一律忽略（drop/dragover preventDefault）。
- **不可识别内容**：任何未知/不支持语法（HTML 标签、Setext 下划线等）按字面文本呈现，不报错。
